
# ⚡ Next.js App — Projeto Inicial Moderno

Aplicação criada com **Next.js (App Router)**, focada em **performance**, **experiência do desenvolvedor** e **escalabilidade**. Este projeto serve como base moderna para aplicações web profissionais, utilizando **React**, **TypeScript**, **Tailwind CSS** e integração pronta para deploy.

---

## 🚀 Visão Geral

Este projeto representa o **setup inicial padrão do Next.js**, ideal para:

* Landing pages modernas
* Dashboards
* E-commerces
* Sistemas web escaláveis
* Projetos pessoais e profissionais

Com hot reload instantâneo, estrutura organizada e boas práticas desde o início.

---

## 🧠 Tecnologias Utilizadas

* **Next.js 14+** — Framework React full-stack
* **React 18** — Componentização moderna
* **TypeScript** — Tipagem estática e segurança
* **Tailwind CSS** — Estilização utilitária e responsiva
* **Next/Image** — Otimização automática de imagens
* **Vercel** — Deploy rápido e confiável

## ▶️ Como Rodar o Projeto

### 1️⃣ Instalar dependências

```bash
npm install
```

### 2️⃣ Iniciar servidor de desenvolvimento

```bash
npm run dev
```

Abra no navegador:

```
http://localhost:3000
```

---

## ✏️ Editando a Aplicação

Comece editando o arquivo:

```ts
src/app/page.tsx
```

As alterações são refletidas **instantaneamente** no navegador.

## 🌐 Deploy
